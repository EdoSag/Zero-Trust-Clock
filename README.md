# Zero-Trust Clock

Alarms, timer, stopwatch, world clock and bedtime (on the phone: **ZT Clock**).
Same account, settings and look as the other Zero-Trust apps, built on
[Zero-Trust-Core](https://github.com/EdoSag/Zero-Trust-Core).

Work happens on the `Dev` branch; `main` holds releases.
